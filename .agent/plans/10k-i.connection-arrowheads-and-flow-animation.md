# Plan 10k-i: Connection Arrowheads + Flow Animation

**Complexity: Medium.** Self-contained addition to `renderN8nDiagram`'s connection-drawing
loop; no structural risk to existing node/zone rendering. First of 10k's four sub-plans.

## Requirement

`docs/ARCHITEQ-n8n-Canvas-Complete-Spec.md` 3.7 (animated flow-dot on primary-path edges)
and 3.8 (arrowheads, colored per edge semantic color). Neither exists today — confirmed via
direct grep (no `<marker>`, no `animateMotion`, anywhere in `decompose.js`).

## Scope decisions

1. Exact values read from `reference/architeq-ux-mockup.html`'s own source, not
   approximated: marker `markerWidth`/`markerHeight`=8, `refX`=6, `refY`=3, arrow path
   `M0,0 L6,3 L0,6 Z`; flow-dot `r`=3, `dur`=1.8s, `repeatCount`=indefinite.
2. "Primary-path" = every connection except `local_branch` (mirrors the mockup's own
   `n8nEdgeList` split: the chained sequence is `kind:'primary'`, the one designated branch
   edge is `kind:'branch'`; our own real classification already distinguishes
   `local_branch` from everything else the same way).
3. Two markers, not one: `accent`-colored for primary paths, `warning`-colored for
   `local_branch` (matches each connection's own stroke color, per 3.5/CSS already in
   place).
4. Direction matches execution order already: waypoints are always built
   source-output -> target-input, so an `animateMotion` using the same path string
   animates forward (source to target) with no extra reversal logic needed.

## Build

- `static/js/decompose.js`, `renderN8nDiagram`: add an SVG `<defs>` block (once per diagram,
  not per connection) with two `<marker>` elements. Set `marker-end` on every connection
  `<path>`, selecting the marker by classification. Append a `<circle>` + `<animateMotion>`
  for every non-`local_branch` connection, reusing that connection's own path string.
- `static/css/style.css`: marker fill colors via `var(--accent)`/`var(--warning)` (no new
  color values — both tokens already exist and already color these same connections'
  strokes).

## Test

Real Playwright screenshot of the real `rag` domain's n8n canvas, per DP14: confirm
arrowheads render at every connection's target end, confirm the `local_branch` connection's
arrowhead is warning-colored while every other connection's is accent-colored, confirm
`animateMotion` elements exist on non-branch connections and are absent from the branch
connection (a static screenshot can't show motion directly — confirmed instead via DOM
query: `animateMotion` element count equals non-branch connection count, `path`/`d`
attribute on each matches its own connection's real path string). Full pytest suite
(no backend touched, expect unchanged pass count).
