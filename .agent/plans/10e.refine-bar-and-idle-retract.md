**Complexity: Simple.** Frontend-only, small and self-contained per the top-level plan's
own description. Proceeds through Build/Test/Commit per the Autonomy Default.

## Requirement

Part of `10.ui-shell-rebuild.md`: "persistent refine bar (collapse/expand, idle-retract),
detail panel idle-retract." Traced the reference mockup's own JS (`expandRefineBar`/
`collapseRefineBar`/`armRefineIdleRetract`, `armPanelIdleRetract`) for the exact interaction
being asked for.

## Scope decisions

1. **Collapse/expand only, not re-positioning.** The refine bar's current CSS renders it
   inline in the canvas document flow (not the mockup's `position:absolute` floating pill)
   -- that's a separate layout decision nobody has asked to change here; 10e adds the
   collapsed-pill/expanded-fields behavior on top of the existing layout, not a re-position.
2. **Idle-retract timers are module-level (`let refineIdleTimer`/`panelIdleTimer`), not
   `state` fields** -- mirrors the mockup's own approach and this codebase's own precedent
   for transient, non-rendering bookkeeping (10d's `treeRevealed` direct-mutation note).
   Since `renderBoard()` tears down and rebuilds the whole DOM on every state change, a
   fired timeout re-queries the *current* DOM/state at fire time rather than trusting a
   captured element reference from whenever it was armed.
3. **Same timing as the mockup** (6s refine-bar idle, 7s panel idle) -- arbitrary but
   real, cited values, not re-invented.
4. **Refine bar collapses on successful submit**, stays expanded on error (so the user can
   see the error message and retry) -- a small, deliberate deviation from the mockup's
   "always collapse on submit" (the mockup has no real error path to preserve).

## Build (`static/js/decompose.js`, `static/css/style.css`)

1. `state.refineBarExpanded: false`, reset in `selectDomain`.
2. `expandRefineBar()`/`collapseRefineBar()`/`armRefineIdleRetract()` (module-level timer).
3. `renderRefineBar()`: collapsed state renders a small "✦ Refine" pill (click ->
   `expandRefineBar`); expanded state renders the existing input/button, with `input`
   arming the idle timer on `input`/collapsing on `blur` (if empty).
4. `submitRefine()`: collapses the bar on success (leaves it expanded on error).
5. `panelIdleTimer`/`armPanelIdleRetract()`; `renderNodeDetailPanel()`'s `drawer` gets
   `mousemove`/`keydown`/`input`/`click`/`scroll` listeners that re-arm it; armed once when
   the panel first renders; `closeNodeDetail()` clears the timer.
6. `style.css`: `.decompose-refine-bar.collapsed`/`.expanded`, `.decompose-refine-pill`.

## Test

Standalone Playwright harness: clicking the collapsed pill expands the bar and focuses the
input; typing then waiting past the idle timeout (test uses a short timer override or
`page.clock`) collapses it back only if the input is empty; opening the node detail drawer
and waiting past its idle timeout closes it (`state.selectedNodeId` becomes `null`) when no
interaction occurs, but a real interaction event re-arms it and keeps it open. Zero JS
errors.
